CaptureHub – Photography Showcase

CaptureHub is a photography showcase website created using HTML and CSS.
The main purpose of this project is to practice and demonstrate different CSS concepts while creating a clean, modern, and responsive photography-themed webpage.

✨ Features
Sticky header with navigation links
Hero section with background image and buttons
Photography categories section
Photo gallery with different card layouts
Photographer spotlight section
Photography stories section
Simple contact form
Footer with navigation and social links
Hover effects and smooth transitions
Responsive layout for different screen sizes
